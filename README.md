# Simulation-Based-Robot-Manipulation-for-Drone-Battery-Replacement
Design and Isaac Lab simulation of two robotic end-effectors for automated drone battery replacement — a dual-battery belt gripper and a suction-assisted parallel gripper — with deep RL (PPO) on a UR10 replacing analytic IK. Policy cut end-effector alignment error from 1.05 m to &lt;7 cm.
